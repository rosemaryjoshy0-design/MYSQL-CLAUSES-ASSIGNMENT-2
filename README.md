# SQL Queries & Joins

## Key Concepts Covered
* **Filtering & Conditions:** `WHERE`, `IS NULL` / `=`, pattern matching
* **Aggregations:** `MIN()`, `AVG()`, `COUNT()`, `GROUP BY`
* **Joins:** `INNER JOIN`, `RIGHT JOIN` across relational tables (`EMPLOYEES` and department/project tables)
